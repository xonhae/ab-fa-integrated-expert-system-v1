// part 01 · the true challenge

IC 故障診斷的底層挑戰

🔌 電性表徵與物理失效的映射

機台測試給出的是「症狀」(如漏電、電壓漂移)，但對應的「病因」(物理失效機制) 卻是高度非線性的。一個漏電特徵可能同時指向 金屬殘留微短路 或 閘極氧化層崩潰。

📉 數據維度災難與雜訊干擾

從晶圓尺寸量測、電漿機台狀態到可靠度數據，參數維度極高且伴隨製程變異雜訊。單憑人類大腦經驗，已經無法在幾分鐘內完成多維度交叉比對與機率收斂。

在先進節點製程中，IC 故障診斷的難度呈指數級上升。我們面臨的真正挑戰是什麼？

首先是電性表徵與物理失效的非線性映射。當 WAT 測試顯示 IDDQ 異常飆高時，它只是一個「症狀」。導致這個症狀的物理機制可能有很多：是金屬層的微粒殘留造成的微短路？還是離子植入異常？又或者是閘極氧化層的早期崩潰？傳統上，這極度仰賴資深工程師的「直覺」，容易產生誤判。

其次是數據維度的災難。我們需要同時檢視 CD 不均勻度、Overlay Error、蝕刻的 Plasma 偏差等十多項參數。這些參數本身還帶有正常的製程變異雜訊。要在龐大的數據矩陣中找出 Root Cause，單靠人工經驗已無法滿足高效率的量產需求，我們需要一套確定性的數學模型來輔助。

Browser-Native 架構革新

徹底捨棄後端伺服器。所有複雜的矩陣運算、貝氏推論與動態渲染，皆透過瀏覽器在本地端執行，完全支援晶圓廠無塵室的封閉網路環境。

02
UI/UX：雙向綁定與即時重繪

採用現代化的毛玻璃 (Glassmorphism) 設計。滑桿與數值框採零延遲雙向綁定，任何輸入狀態變更，都能在 10 毫秒內完成全局畫面與機率計算的瞬間重繪。

為了解決上述挑戰，我們在 Wafer-Pro 的架構上進行了根本性的重構。如同背景跳動的神經網路，我們的系統也充滿了即時的連結。

第一大亮點是 Serverless 純前端計算引擎。我們砍掉了原本笨重的 Python 後端，將所有的數學推論、可靠度公式與繪圖邏輯，全部濃縮為輕量級的 JavaScript 引擎。這不僅讓系統能在無塵室的嚴格內網甚至完全離線的狀態下運行，更消除了所有網路延遲。

第二大亮點是 UI 與 UX 的設計。我們採用了 Glassmorphism 毛玻璃特效與 Cyberpunk 高對比色系，呈現出極具科技感的專業儀表板。更重要的是，介面中的滑桿與輸入框採用了雙向資料綁定 (Two-way data binding)，任何微小的數值調整，都能在 10 毫秒內觸發底層引擎，瞬間重繪所有的機率條與視覺化圖表，達到「人機一體」的流暢感。

PART 03 · DYNAMIC FEATURE EXTRACTION

動態特徵擷取與證據綁定

量化參數輸入

  • 線寬 3-Sigma: 評估曝光/蝕刻的均勻度
  • 層間對位誤差: 評估黃光微影的精準度
  • 靜態漏電流 (IDDQ): 判斷短路與漏電的核心
  • 電漿參數偏差: 監控乾蝕刻機台的穩定度

激發函數 (Activation Function)

系統為每項證據定義了「正常區間」與「異常警戒線」。

當工程師輸入的數值越偏離正常區間，觸發該特徵的權重分數就會以非線性的方式急遽飆升，完美模擬資深工程師的危機意識與直覺反應。

接下來，我們深入探討系統如何處理源源不絕的數據流：也就是動態特徵擷取與證據綁定。

在我們的介面上，工程師可以輸入高達十幾項的關鍵參數，包含 CD 的 3-sigma 變異、黃光的 Overlay Error、WAT 的 IDDQ Ratio 漏電倍率等等。但這些數字不能只是被記錄下來，它們必須被「量化評估」。

我們在系統內部實作了類似神經網路的激發函數 (Activation Function)。我們為每一項參數定義了業界標準的「正常界線」與「強觸發異常界線」。當滑桿拉動時，系統並非線性地處理數據，而是當數值越逼近異常閾值時，該證據的權重分數會以非線性的方式飆升，這完美模擬了資深工程師在看到極端異常值時所產生的「強烈危機意識」。

PART 04 · INFERENCE ENGINE

貝氏推論決策引擎

權重評分機制

每種缺陷都有其敏感度權重。系統會將工程師輸入的證據強度，與該缺陷的敏感度相乘後加總，得出原始吻合度分數。

原始吻合度 = 加總 ( 證據強度 × 缺陷敏感度 )

信心度正規化

為了過濾雜訊並突顯最可能的根本原因，系統會將吻合度分數進行指數放大，並轉換為 100% 滿分的相對機率。

最終機率 = (特定缺陷分數)^p / 總分數和

核心中的核心，是我們的推理引擎與機率正規化演算法。就像背景中的知識圖譜一樣，它將各種證據串聯起來。

首先是權重評分矩陣。我們將半導體常見的 10 多種缺陷模型（例如金屬微粒、氧化層崩潰等）建立了一個龐大的敏感度矩陣。當證據輸入時，系統會計算證據強度與該缺陷權重的內積，得出一個原始的吻合度分數。

但原始分數無法直觀比較。因此我們進行了第二步：信心度正規化。我們不僅將分數轉換為百分比，更引入了一個次方函數。這個演算法的作用在於「拉開差距」：當某個缺陷的吻合度微幅領先時，經過次方放大與歸一化處理，它的機率會被顯著放大，從而幫工程師過濾掉雜訊，強烈收斂並凸顯出真正的根本原因。

PART 04b · CONVERGENCE ALGORITHM

決策收斂演算法：為何會出現 100% 機率？

訊號放大器：30 次冪變換

當多項製程數據同時指向某特定缺陷時，系統透過將擬合分數進行 30 次方放大（Si30），以極端壓制製程變異產生的雜訊，凸顯最顯著的失效特徵。

P(i) = Si30 / 加總 ( Sj30 )

線性平分 vs 冪次收斂

以「0.9 符合度」與「0.7 符合度」的缺陷為例，傳統算法會讓兩者機率非常接近，而 30 次方放大的贏家全拿（Winner-Takes-All）演算法，則能給出果斷的臨床決策：

指標 / 算法 典型缺陷 A (0.9) 干擾缺陷 B (0.7)
傳統線性分配 42.8% (模糊) 33.3% (模糊)
30次冪收斂 99.95% (確診) 0.05% (消除)

在日常診斷中，工程師可能會好奇：為什麼當數據輸入後，最可能的缺陷往往會直接顯示 100% 的機率？這合理嗎？

答案是：這在數學上非常合理，而且是為了精準決策而刻意設計的。背景的鏈式反應特效，正代表著多項證據融合時的指數級放大效應。

當工程師輸入一組數據時，如果缺陷A的符合度是0.9，缺陷B是0.7。在傳統線性平分下，兩者的機率分別是43%和33%。這會讓排班的FA分析人員非常困惑，無法判斷該進行哪種昂貴的破壞性物理檢測。

為此，Wafer-Pro 引入了30次冪的 Power-Softmax 正規化演算法。在30次方放大下，0.9與0.7的微幅差距，其權重分量會被拉開到 1880 倍！因此最終計算出的機率，領先者會直接衝上 99.95%（四捨五入後為 100%），而干擾項則被壓制到接近 0%。這實踐了『贏家全拿』的統計收斂，能大幅降低雜訊，讓晶圓廠能秒級定位問題，實現真正的快速精準決策。

PART 05 · DYNAMIC SVG RENDER

SVG 即時渲染晶片剖面圖

SVG
即時渲染晶片剖面圖 (Cross-section)

不再依賴靜態圖片或文字報告！系統會根據運算出的最高機率缺陷，透過前端程式碼即時繪製微觀結構圖。

若判定為「金屬微短路」，系統會在兩條金屬線之間動態畫出殘留物；若判定為「斷路空洞」，則會在地層中呈現中斷的結構缺口。

有了精準的機率數字還不夠，我們必須將它「物理化」。這就是我們的 物理失效拓撲動態生成 功能。背景的星座連線特效象徵了我們勾勒出的晶片幾何輪廓。

過去的系統往往只能給出一段文字結論。但在 Wafer-Pro 中，我們利用純前端的 SVG 繪圖技術，即時渲染出晶片的剖面結構圖。當系統計算出最高機率的失效是金屬跨橋 (Bridging) 時，SVG 引擎會立刻在兩條金屬導線之間繪製出殘留的短路塊；如果是斷路 (Open)，則會畫出 Via 或金屬層的空洞。

這種透過數學機率直接驅動幾何圖形變形的技術，完美地在電性數據與物理結構之間搭起了一座橋樑，讓工程師能一眼看出失效的微觀樣貌。

// part 06 · multi-dimensional distribution

六大物理分類動態雷達圖

將複雜收斂為直觀

  • 短路 (Bridge): 金屬殘留、微粒跨橋
  • 斷路 (Open): 蝕刻不足、應力斷線
  • 對位 (Overlay): 曝光層嚴重偏移
  • 氧化層 (Oxide): 閘極擊穿、漏電
  • 熱效應 (Thermal): 局部融毀、熱點
  • 材料層 (Material): 介面剝離、水氣腐蝕
Hexagonal Radar Chart

將底層數十種細項缺陷機率，
自動聚合到這六大宏觀維度，
協助廠長或整合工程師 (PIE) 一秒看懂整批晶圓的異常偏誤方向。

在微觀拓撲之外，我們也提供了宏觀的視角：多維度缺陷物理分類雷達圖。如同背景的軌道光環，機率在不同維度間動態分佈。

晶片缺陷有成百上千種細項，但歸根究底，物理行為不外乎短路、斷路、對位異常、氧化層異常、熱效應以及材料異常等六大類。系統會將底層計算出的數十種缺陷機率，自動聚合到這六個維度，並繪製成動態的六邊形雷達圖。

這個功能對製程整合工程師 (PIE) 或廠長非常關鍵。當雷達圖的重心嚴重偏向「Oxide」與「Thermal」時，他們不需看密密麻麻的細節數據，就能立刻知道該去檢查擴散爐管 (Furnace) 的溫度曲線或是 CVD 機台的電漿狀態，大幅提升決策效率。

// part 07 · reliability modeling

先進可靠度數學建模

電遷移 (EM)

Black's Equation: 透過「導線電流密度」與「金屬活化能」，即時推算金屬互連導線的平均故障時間 (MTTF)。

介電層崩潰 (TDDB)

Weibull 分佈模型: 計算晶片在特定「電場強度」與「溫度」下，其氧化層隨時間老化的累積失效機率。

熱疲勞 (Thermal Fatigue)

Coffin-Manson 模型: 評估封裝凸塊 (Bump) 在嚴苛熱循環試驗中的彈塑性應變壽命。

水氣腐蝕 (Moisture Corrosion)

Peck's Law: 分析在溫濕度偏壓試驗中，水氣滲透對金屬層造成的腐蝕加速影響。

除了早期的良率失效診斷，Wafer-Pro 更進一步整合了先進可靠度數學建模板塊。這也是系統深度的體現，如同背景的連鎖反應，可靠度失效是隨著時間慢慢推進的。

我們將業界標準的 JEDEC 可靠度模型全部以 JavaScript 實作寫入系統中。舉例來說，針對導線的電遷移 (EM)，我們實作了 Black's Equation，工程師只要拉動電流密度或溫度的滑桿，系統就能即時繪製出對數座標下的 MTTF 壽命衰減曲線。

針對閘極氧化層崩潰 (TDDB)，我們使用了 Weibull 分佈模型；針對熱疲勞與濕度腐蝕，我們分別內建了 Coffin-Manson 模型與 Peck's Law。這不僅是一個靜態的參考書，而是一個強大的「互動式可靠度模擬器」，能在前端 Canvas 上即時畫出隨時間衰退的機率圖表。

// part 08 · auto disposition

自動化專家分析報告與文獻庫

01
報告自動撰寫與工程系統整合

系統會將診斷機率、觸發異常的原因 (Reasoning Trace) 以及後續的 FA 檢測實體建議，自動匯整為純文字報告，可一鍵無縫貼入公司的 Lot Log 系統中。

02
內建國際可靠度規範檢索

系統內建了標準的 JEDEC/IEEE 可靠度規範文獻連結（如熱循環測試標準），確保所有的參數設定與診斷建議，都有最高標準的工業界權威背書。

再強大的推理引擎，最終都要落地到工程師的日常作業中。所以我們實作了自動化專家分析報告功能。大家看背景打字機的特效，象徵著這一切自動化生成的過程。

當工程師確認診斷結果後，只需點擊一個按鈕，系統就會自動將候選缺陷的機率、推理鏈的邏輯，以及下一步的實體檢驗建議（例如是否要進行 FIB 截面分析或 EMMI 漏電定位），匯整成排版精美的 Markdown 報告。這份報告可以直接複製貼入公司的 Lot Log 系統中，大幅節省打字時間，並統一了 FA 的報告格式。

同時，系統還內建了詳盡的 JEDEC 與 IEEE 規範文獻庫，無論是引用模型還是制定實驗計畫，都能在系統內找到權威背書。這真正實現了作業流程的閉環。

總結：引領分析流程的典範轉移

商業核心價值

  • 極速決策: 將過去需要數小時的跨部門數據分析，縮短為秒級的互動運算。
